▸ TROUBLESHOOTING
If you see Network error or Load failed: this is a browser CORS restriction, not a bug in the app. The fix:
  • Open this file directly in Safari (mobile) or Chrome/Safari (desktop) instead of inside Claude's preview
  • If using Claude's preview on iOS, try the Open in Browser option from the share menu
